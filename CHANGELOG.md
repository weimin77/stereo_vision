# Changelog

All notable changes to this project are documented in this file. It is generated by
[semantic-release](https://github.com/semantic-release/semantic-release) from the commit history;
the entries below are the initial state before the first automated release.

## 0.1.0

### Features

- Epipolar rectification: `stereoRectify`, undistort maps, common-ROI cropping, rebased `Q`/`P`,
  and a validity mask built by remapping a white image
- `cv::StereoSGBM` wrapper with padding, 1/16 px fixed-point unpacking, search-window clipping and a
  sub-pixel left-right consistency check
- Depth from `Z = fx * |Tx| / (d - doffs)`, honouring the principal-point offset between the
  rectified views
- Point cloud back-projection in the rectified left camera frame, written as PCD or PLY (ascii or
  binary) without a PCL dependency; each point is `x y z` only, with no per-point colour
- `colorize` on the two map writers: the default keeps the measurement encoding, `true` writes an
  8-bit `COLORMAP_TURBO` view stretched over the 5th-95th percentile, invalid pixels black, near warm
- `sv::Pipeline` facade: `set_input_image`, `run` (compute only), `get_*` and `save_*`
- `sgbm_config.json` parsing with profile merging and derivation of `num_disparities` from the
  working depth range

### Documentation

- Doxygen landing page and tutorial (`docs/doxygen/dox`), bilingual en/zh
- Sphinx pages for the pipeline, the CMake/Conan/metadata contracts and a worked example

### Tests

- GTest unit suite covering types, image I/O, calibration, rectification, matching, depth, point
  clouds, configuration and the pipeline facade, plus a repeated-run stress case
- `test_package/main.cpp` runs the BlenderProc oven scene in `test_package/resources/oven` end to end
  and checks it against the scene's own disparity and depth ground truth, reporting wall-clock time
  per phase and the process's peak resident memory
